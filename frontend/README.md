# Metis Frontend

React-based dashboard for the Metis PII Redaction Engine.

## Tech Stack

- **React 18** with TypeScript
- **Vite** for fast builds
- **Tailwind CSS** for styling
- **React Joyride** for interactive walkthroughs

## Setup

```bash
npm install
npm run dev
```

The frontend will be available at `http://localhost:5173`.

## Features

- File upload with drag-and-drop support
- Real-time redaction progress tracking
- Interactive compliance score dashboard
- Filterable job history data grid
- Reversible vault unlock interface
