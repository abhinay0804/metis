# Metis Results & Examples

This directory provides a quick glimpse into what **Metis** does behind the scenes to protect your data and analyze documents for compliance.

## Example 1: HR Onboarding Memo

In this scenario, an HR professional uploads a sensitive internal memo containing an employee's personal and financial details.

### 1. Original Document
[`sample_document.txt`](./sample_document.txt)
*A raw text file containing highly sensitive information like SSN, Banking routing numbers, personal email, and phone numbers.*

### 2. Masked Document
[`masked_document.txt`](./masked_document.txt)
*The output produced by the Metis Data Masking engine. Notice how the system uses contextual NLP (via Presidio) to automatically identify and replace sensitive entities with `[REDACT]` placeholders, while perfectly preserving the document's structure and non-sensitive text.*

### 3. Analysis Report
[`analysis_report.json`](./analysis_report.json)
*The output produced by the Metis Analysis Engine. The system accurately tallies the number of sensitive fields exposed, assesses the overall Risk Level, and cross-references the findings against major compliance standards (e.g., GDPR, CCPA, HIPAA) to provide actionable recommendations.*

---

*These files are completely generated by the backend AI and NLP engines of Metis and reflect exactly what you would see when using the application's dashboard.*
